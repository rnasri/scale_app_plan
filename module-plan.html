F0 — Foundation (prerequisite for everything)

What F0 delivers

  • Frappe bench (version-15) running — local macOS native bench per developer, shared staging on AWS
  • ERPNext + Frappe CRM + Frappe HR + India Compliance installed
  • scale app (in repo at apps/scale/) installed and migrated — branding, SSO hooks, audit log, Event Outbox DocType, AIWS Config Profile DocType
  • Multi-site provisioning: first client site created, admin access verified
  • CI/CD pipeline: GitHub Actions → staging auto-deploy on every PR merge to develop
  • Backup strategy: daily automated backup to S3
  • Developer onboarding: every team member can spin up a local bench in under 30 minutes

F0 gate — do not start Wave 1 until all are true

  • A developer who was not involved in setup can create a new site from scratch using documented steps
  • CI passes on a dummy PR to scale
  • Staging site accessible at a real URL (not localhost)
  • Backup verified: a restore from backup works on a fresh bench
  • ERPNext Selling, CRM, HR modules enabled on the staging site

F0 is not a soft prerequisite. Starting Wave 1 before F0 is complete means developers will be building on an unvalidated platform — and fixing CI/infra issues in parallel with feature work. That destroys velocity.

Module implementation checklist — template for every module

When building any module, it is "done" only when all of these are true:

Development

  • Custom fields exported as fixtures and committed to the app repo
  • Custom DocTypes created with Python controllers and tests
  • Server Scripts tested with edge cases covered
  • Background jobs registered in hooks.py and tested on staging
  • All custom APIs decorated with @frappe.whitelist() and permission-tested
  • Patch script added if any data migration was needed
  • Integration connectors mocked in tests; real credentials in Settings DocType

Quality gate

  • Test suite passing on CI (GitHub Actions)
  • Module installed cleanly on a fresh staging site (no manual steps)
  • End-to-end flow walkthrough completed by the module owner on staging
  • Cross-module links verified (linked DocTypes resolve correctly)
  • Reports loading without errors for all user roles
  • Permissions verified: each role can only access what they're supposed to
  • Module reviewed by Raghib (Product Lead sign-off)
  • Tracker in AIWS_ERP_MODULES_CONTEXT.md updated
