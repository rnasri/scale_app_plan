04 / 20
Worth Knowing Before The Walkthrough

Two Real Corrections To The Plan, Found On Day One

Caught While Confirming Phase 1, Fixed Before Anyone Saw Them
  • "Phantom BOM" doesn't exist on this system's actual version. The plan assumed a newer ERPNext feature (pass-through sub-assemblies that skip stocking an intermediate item) — grepped the entire manufacturing module directly, zero references anywhere. If the client genuinely needs it, that's a version upgrade, not something buildable on top.
  • A brand-new item's BOM cost silently shows zero until it has a real stock transaction — the system prices Bill of Materials from an item's actual buying history by default, not whatever number is typed into the form. Confirmed live and documented so it isn't mistaken for a bug during setup.

MFG-07

Batch / Job Costing

🟢 Progressed
See exactly what a production run actually cost — materials plus labour time — versus what it should have cost.
Confirmed Live
  • A real ₹600/hour workstation, a 60-minute planned operation, and a Job Card logging 90 actual minutes — planned cost (₹600) and actual cost (₹900) both computed correctly and sit side by side on the Work Order, a genuine ₹300 overrun visible the moment the Job Card is submitted
One Precision
  • There's no dedicated "variance" field or report — it's two real numbers on the same document that get compared, not an automatic percentage. Worth knowing before demoing this as a single number
