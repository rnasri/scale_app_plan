The Rule, As Built
  • 5 states: Draft → Pending Manager Approval → Pending VP Approval → Approved / Rejected
  • Discount ≤ 20% → Sales Manager can approve directly
  • Discount > 20% → Manager cannot approve — must escalate to VP (Sales Master Manager)
  • Rejected → Sales User can Revise → back to Draft to try again
Native Frappe Workflow — buttons appear automatically in the form toolbar per role, no custom code needed to render them.

scale_sales_collection_statusscale_sales_promise_to_pay_datescale_sales_dunning_reminders_sent
Home→Scale Sales workspace→Sales Invoice→SINV-26-00001→More Info tab → Additional Info
What's Actually Automated vs. Manual
  • Promise-to-Pay + Collection Status — real: auto-set to Pending on submit, auto-flips to Collected (or Partial, on part-payment) as payments post
  • Dunning reminders + escalation — real, as of 7 Aug: a daily job emails T-7/T-0 reminders and auto-creates + submits a T+15 Dunning document using the matching Dunning Type's interest rate, with a tracking field so nothing repeats twice
  • Ageing buckets — real: Accounts Settings drives the 30/60/90/120 columns on the native Accounts Receivable report
Both invoice fields sit on the More Info tab, inside the collapsed Additional Info section — not on Details. Frappe also auto-hides empty fields on a submitted document, so an unset Promise-to-Pay Date won't show at all until a value is entered.
